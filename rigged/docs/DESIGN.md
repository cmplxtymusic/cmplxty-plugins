# RIGGED design

An original randomizable effects rack. Eleven processors (Filter, Drive, Crush, Ring, Chorus, Phaser, Delay, Reverb, Comp, Tremolo, Width) run in a user-ordered chain. Each has on/off, a LOCK that excludes it from RANDOMIZE, and automatable parameters. A roll moves unlocked parameters from their current values by AMOUNT, inside musical, level-safe ranges, and is recorded for undo/redo. RANDOMIZE is itself a parameter and rolls on a low-to-high edge. Delay and tremolo follow the host tempo. Gain match uses a K-weighted envelope so rolls stay within a tight loudness window. The safety limiter is a linked, zero-lookahead sample-peak ceiling at −1 dBFS, on by default. The dice is decorative. Filter is a 2-pole TPT SVF. Coefficients update at block rate; disabled effects are skipped. Inspired by the idea of a lockable, randomizable rack, not a recreation of any existing product.

# cmplxty-plugins

Free plug-ins and apps by CMPLXTY. Each one lives in its own folder.

- [`glitch-crusher/`](glitch-crusher/) - CMPLXTY Glitch Crusher (VST3 + CLAP), GPLv3
- [`growl-saturator/`](growl-saturator/) - CMPLXTY Growl, bass growl saturator (VST3 + CLAP), GPLv3
- [`yoink/`](yoink/) - Yoink, find YouTube clips by phrase and drag the audio into your DAW (Windows + Mac), MIT

CI workflows are in `.github/workflows/` (one per project). The Mac Yoink installer is built by "Build Yoink for Mac".
